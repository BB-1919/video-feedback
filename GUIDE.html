Video Feedback — Guide

Pause a video and write down what to fix, pinned to that exact moment. Hand the notes to an AI (Claude Code and others), a person, or an editing app. It runs only on your computer; your videos never leave it.

1Setup — Python 3 (free · once)

The program runs on a free tool called Python. You install it once.

Mac

Usually already there. If not, the first start shows “install the command line developer tools?” → click Install, then start again when it is done.

Windows

  1. Go to python.org/downloads and click “Download Python”.
  2. Run the downloaded file.
  3. At the bottom of the first screen, tick “Add python.exe to PATH”, then “Install Now”.
Example — bottom of the first Python installer screen on Windows (it may look slightly different)
✓ Use admin privileges when installing py.exe
✓ Add python.exe to PATH ← be sure to tick this
Forgot to tick it? Run the installer again → “Modify” → Next → tick “Add Python to environment variables”, or uninstall and install again.

2Start

Double-click the zip you downloaded to unpack it. You get a VideoFeedback_v1.5.0 folder; keep it anywhere you like (Documents, for example).

Mac — Start-Mac.command

  1. Double-click it.
  2. The first time, macOS says it “cannot be opened · unidentified developer” → click Done (or OK).
  3. System Settings → Privacy & Security → scroll down → “Open Anyway” → password → Open.

On older macOS you can also right-click the file → Open → Open. After allowing it once, just double-click from then on.

Windows — Start-Windows.bat

  1. Double-click it.
  2. If a blue “Windows protected your PC” box appears → More info → Run anyway.

Drop a video folder onto this file to open that folder right away.

Example — the Windows “protected your PC” box
Windows protected your PC
Microsoft Defender SmartScreen prevented an unrecognized app from starting…
More info → Run anyway

A page then opens in your browser (Chrome, Edge or Safari). The first time it shows your Movies / Videos folder (or your home folder).

It stops by itself when the page has not been used for 30 minutes. To use it again, double-click the start file again. Your notes stay where they are.
Language Click ⓘ at the top right of the page → 한국어 / English.

3A look around

  • 1Folders · Videos — pick a video. F find by name · ⌫ up a folder · [ ] previous · next video. Videos with notes show how many. The box above the list sorts by newest first (default) · by name · oldest first; folders are sorted by the newest video inside them (the folder with the video you just made comes first).
  • 2Video — Space play · pause, ← → 2 seconds. Red marks on the strip under the video are notes (click to jump there); green ones are fixed.
  • 3Note box — see section 4.
  • 4Note list — in time order. Click a note to jump to its moment. Purple = a “whole video” note, green = fixed.
  • 5Done — when you have finished, hand everything to an AI (section 6).
Screen size The video resizes to the window height, so writing a note never hides the top of the video (a Shorts title, for example).

Resize panels · use two monitors

  • Panel width — hover over the vertical line between two panels and it turns blue. Drag it to change the width. Push the left or right panel all the way to fold it; click the folded line to open it again. Double-click the line for the default width.
  • Pop out the video — press W (or “⧉ Pop out video” under the video) and the video, timeline strip and play buttons move into their own window. Drag that window to your other monitor and make it as big as you like. “⛶ Full screen” on top fills the screen with it (Esc to leave).
  • Other panels too — the ⧉ on the folder, note and feedback panels pops that panel out as well. The space it leaves folds away so the other panels get wider.
  • Put it back — close the popped-out window or click “↩ Put back” on top of it. Shift+W puts every panel back at the default width.

Shortcuts work the same in every window. Press M in the popped-out video window and the note box comes down into that window; save the note or press Esc and it goes back. Panel widths and the position and size of popped-out windows are remembered for next time.

4Leaving notes

  1. While watching, just start typing in the note box — the video pauses and the time is attached. (Or press M.)
  2. Press Enter when done. Shift+Enter starts a new line.

A note on a range

I range start → move the video → O range end → write the note. The range is colored on the strip under the video. X clears the range.

A note about the whole video

For requests that are not about one moment — color, quality, loudness — press G (“Whole-video note”). In the note box, Option+1–7 picks a category (Color/LUT · Filters/effects · Quality/resolution · Frame rate (fps) · Volume/music · Caption style · Other). The category is optional.

The same note on several videos

Something that applies to many videos, like “make the color a bit warmer”, can be written once.

  1. Click “☑ Note on several videos” at the top left (Shift+G). A box appears in front of each video name.
  2. Click a video to pick it, click again to unpick. Hold Shift to pick everything in between, or use “All in this folder”. You can go to other folders and pick more; what you picked stays picked.
  3. “🌐 Whole-video note on n picked” (Shift+G again) → pick a category (optional), write the note, Enter.

Each video gets its own “whole video” note. You can open that video later to edit or delete it, and Done hands each video over separately. The window stays open after saving, so you can write another note for the same videos right away. Esc once closes the window; once more ends picking.

Windows The Mac Option key is Alt, and ⌘ is Ctrl. Shortcuts work whatever keyboard language is on.

5Edit · delete

  • Pick a note with ↑ ↓ and the video jumps there → E edit · C mark done · D twice to delete.
  • Delete several: pick them with the small box on the left of each note (or V) → “Delete picked” (Shift+D).
  • Delete all: Shift+X — every note on the current video.
  • Every delete needs two presses within 3 seconds. It cannot be undone.
  • Notes the AI has fixed turn green with ✓ done · what was changed (bottom of the picture above). Not happy? Click “✓ Done” to turn it back into “needs another fix”.

6Done → hand it to an AI

Go through all your videos and press “✅ Done” just once at the end (Shift+Enter). Every video with notes that have not been sent yet goes in one go.

The request is copied the moment you press it. It says “each video folder has a feedback file — read it and make the changes”, so you can paste it into any AI window (⌘+V · Windows Ctrl+V). With Claude Code it can also go straight in, as below.

1⚡ Send automaticallyEach video goes to the Claude Code window you have open in its folder. If there is none, a new window opens in that folder. It shows where each one will go first.
2🖥 All to one windowEvery video to one open window (or a new one).
3🎬 Choose per videoPick where each video goes. Picking one folds it so only your choice shows.
4📋 Just copyTo paste it into another AI or send it to a person yourself.
Safe Claude Code windows get the request only through Claude’s own window-to-window messages. Nothing is ever typed into a plain terminal you are working in.
  • Not using Claude Code? 4 Just copy → paste it into your AI. Or switch “AI for a new window” at the bottom to Gemini CLI · Codex · your own command.
  • Sent notes show “→ sent · where”, and next time only new notes go.
  • If the receiving Claude Code window asks whether to accept the message, accept it.
  • Chat-only AIs (web chat and so on) cannot open the folders on your computer, so they can only give advice, not make the changes.

7Export — for a person or an editing app

For handing over the one video you are looking at. Shift+E, then a number.

  1. To an AI — copies the request for this video only.
  2. To a person — saves a PDF with a still of each moment, its time and the note next to the video. Send it by chat or email. (Needs Chrome or Edge.)
  3. To an editing app — a file that puts your notes on the timeline as markers: DaVinci Resolve · Final Cut Pro · Premiere Pro. CapCut cannot import markers, so you get a time list (.txt).

8FAQ

Where are the notes saved?
In “video name.feedback.json” right next to the video. If you rename the video, rename the note file too. Move them together and the notes follow the video.
The video does not play
Chrome and Edge play mp4 (H.264 · HEVC) and mov. Editing formats like ProRes may not play — on a Mac, try Safari.
It says “The program has stopped”
It stopped after 30 minutes without use. Double-click the start file again.
A new version is out?
Download the new zip and use that. Your notes are next to your videos, so they stay.
I want it to work my way
video_feedback.py and video_feedback.html in the folder are the whole program. Show them to your AI and ask for the changes you want.
“⧉ Pop out” does not open a window
The browser blocked the new window. Click the pop-up icon at the end of the address bar, choose “Always allow” for this page, and click again.
The popped-out window keeps opening on my first monitor
Chrome and Edge need your permission to open windows on another monitor. If “🖥 Use this monitor next time” shows on top of the popped-out window, click it and allow (once). If the button is not there, just drag the window over.
Does anything go online?
No. The page only opens on your own computer (other computers cannot open it), and your videos and notes stay in your folders.
