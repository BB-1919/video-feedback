영상 피드백 사용 설명서

영상을 보다가 멈추고, 고칠 곳을 그 장면 시간에 맞춰 적어 두는 프로그램입니다. 적은 메모는 AI(클로드 코드 등) · 사람 · 편집 프로그램에 그대로 넘길 수 있습니다. 내 컴퓨터 안에서만 돌아가고, 영상은 어디에도 올라가지 않습니다.

1준비 — 파이썬 3 (무료 · 한 번만)

이 프로그램은 «파이썬»이라는 무료 도구 위에서 돌아갑니다. 한 번만 설치하면 됩니다.

맥

대부분 이미 들어 있습니다. 없으면 처음 켤 때 «명령어 도구를 설치하겠습니까?» 창이 뜹니다 → 설치를 누르고 끝나면 다시 켜세요.

윈도우

  1. python.org/downloads 에서 «Download Python» 을 눌러 받습니다.
  2. 받은 파일을 실행합니다.
  3. 첫 화면 맨 아래 «Add python.exe to PATH» 를 꼭 체크한 뒤 «Install Now».
예시 그림 — 윈도우 파이썬 설치 첫 화면 맨 아래 (실제 모양은 조금 다를 수 있습니다)
✓ Use admin privileges when installing py.exe
✓ Add python.exe to PATH ← 이것을 꼭 체크
체크를 깜빡했다면 설치 파일을 다시 실행해 «Modify» → 다음 → «Add Python to environment variables» 를 체크하거나, 지우고 다시 설치하세요.

2켜기

받은 압축 파일을 두 번 눌러 풀면 VideoFeedback_v1.5.0 폴더가 생깁니다. 이 폴더는 어디에 둬도 됩니다(문서 폴더 등).

맥 — Start-Mac.command

  1. 두 번 클릭합니다.
  2. 처음에는 «열 수 없음 · 확인되지 않은 개발자» 창이 뜹니다 → 완료(또는 확인).
  3. 시스템 설정 → 개인정보 보호 및 보안 → 아래로 내려 «그래도 열기» → 암호 → 열기.

예전 macOS 는 파일을 오른쪽 클릭 → 열기 → 열기 로도 됩니다. 한 번 허락하면 다음부터는 그냥 두 번 클릭.

윈도우 — Start-Windows.bat

  1. 두 번 클릭합니다.
  2. 파란 «Windows의 PC 보호» 창이 뜨면 → 추가 정보 → 실행.

영상 폴더를 이 파일 위로 끌어다 놓으면 그 폴더가 바로 열립니다.

예시 그림 — 윈도우 «PC 보호» 창
Windows의 PC 보호
Microsoft Defender SmartScreen에서 인식할 수 없는 앱의 시작을 차단했습니다…
추가 정보 → 실행

그러면 브라우저(크롬 · 엣지 · 사파리)에 페이지가 열립니다. 처음에는 동영상 폴더(없으면 집 폴더)가 보입니다.

꺼짐 페이지를 30분 동안 안 쓰면 저절로 꺼집니다. 다시 쓰려면 시작 파일을 다시 두 번 클릭하세요. 메모는 그대로 남아 있습니다.
화면 말 페이지 오른쪽 위 ⓘ → 한국어 / English 로 바꿀 수 있습니다.

3화면 둘러보기

  • 1폴더 · 영상 — 영상을 고릅니다. F 이름으로 찾기 · ⌫ 위 폴더 · [ ] 이전 · 다음 영상. 메모가 있는 영상엔 메모 수가 붙습니다. 목록 위 칸에서 최근 영상순(기본) · 이름순 · 오래된 순으로 바꿀 수 있고, 폴더는 안에 든 가장 최근 영상 순으로 줄 섭니다(방금 만든 영상이 든 폴더가 맨 위).
  • 2영상 — Space 재생 · 멈춤, ← → 2초씩. 영상 바로 아래 띠의 빨간 표시가 메모 자리(누르면 그 장면으로), 초록은 고친 것입니다.
  • 3메모 쓰기 — 아래 4번에서 자세히.
  • 4메모 목록 — 시간 순으로 모입니다. 누르면 그 장면으로 갑니다. 보라색은 «영상 전체» 메모, 초록은 고친 메모입니다.
  • 5피드백 완료 — 다 적었으면 AI 에게 넘깁니다(6번).
화면 크기 창 높이에 맞춰 영상 크기가 저절로 바뀝니다. 메모를 써도 영상 맨 위(쇼츠 제목 자리 등)가 가려지지 않습니다.

칸 크기 바꾸기 · 모니터 두 대로 보기

  • 칸 너비 — 칸과 칸 사이 세로 줄에 마우스를 올리면 파란 줄이 보입니다. 끌면 너비가 바뀝니다. 왼쪽 · 오른쪽 칸은 끝까지 밀면 접히고, 접힌 줄을 누르면 다시 펴집니다. 줄을 두 번 누르면 처음 너비로 돌아갑니다.
  • 영상만 따로 띄우기 — W (또는 영상 아래 «⧉ 영상 따로 띄우기») 를 누르면 영상 · 재생 막대 · 재생 단추가 따로 창으로 나옵니다. 그 창을 다른 모니터로 끌어 원하는 만큼 키우면 됩니다. 창 위 «⛶ 전체 화면» 은 그 창을 화면 가득 채웁니다(Esc 로 나오기).
  • 다른 칸도 — 폴더 · 영상, 메모 쓰기, 피드백 목록 칸의 ⧉ 를 누르면 그 칸도 따로 창이 됩니다. 원래 화면에서 빈 자리는 접혀서 남은 칸이 넓어집니다.
  • 되돌리기 — 띄운 창을 닫거나, 창 위 «↩ 원래 자리로» 를 누르면 제자리로 갑니다. Shift+W 는 모든 칸을 제자리 · 처음 너비로 돌립니다.

단축키는 어느 창에서 눌러도 똑같이 됩니다. 따로 띄운 영상 창에서 M 을 누르면 메모 칸이 그 창 아래로 잠깐 내려오고, 남기거나 Esc 를 누르면 제자리로 돌아갑니다. 칸 너비와 띄운 창의 자리 · 크기는 기억해 두었다가 다음에 그대로 엽니다.

4메모 남기기

  1. 영상을 보다가 메모 칸에 쓰기 시작하면 영상이 멈추고 그 시간이 붙습니다. (또는 M)
  2. 다 쓰면 Enter. 줄을 바꾸려면 Shift+Enter.

구간으로 적기

I 구간 시작 → 영상을 옮겨 O 구간 끝 → 메모. 영상 아래 띠에 구간이 색으로 칠해집니다. X 구간 지우기.

영상 전체에 대한 메모

색감 · 화질 · 음량처럼 시간과 상관없는 요청은 G(«영상 전체 메모»). 메모 칸 안에서 Option+1~7 로 갈래(색감·LUT · 필터·효과 · 화질·해상도 · 프레임(fps) · 음량·음악 · 자막 모양 · 기타)를 고를 수 있습니다. 안 골라도 됩니다.

여러 영상에 같은 메모 한꺼번에

«색감을 조금 더 따뜻하게»처럼 여러 영상에 똑같이 할 말은 한 번에 남깁니다.

  1. 왼쪽 위 «☑ 여러 영상에 한꺼번에 메모» (Shift+G) 를 누르면 영상 이름 앞에 네모가 생깁니다.
  2. 영상을 누르면 골라지고, 다시 누르면 풀립니다. Shift 를 누른 채 누르면 그 사이가 한꺼번에 골라지고, «이 폴더 영상 모두» 도 있습니다. 다른 폴더로 가서 더 골라도 앞에서 고른 것은 남습니다.
  3. «🌐 고른 n편에 전체 메모» (Shift+G 한 번 더) → 갈래를 고르고(안 골라도 됨) 메모를 쓴 뒤 Enter.

영상마다 «영상 전체» 메모가 하나씩 따로 생깁니다. 나중에 그 영상을 열어 고치거나 지울 수 있고, 피드백 완료 때도 영상별로 넘어갑니다. 남긴 뒤에도 창이 열려 있어 같은 영상들에 다른 메모를 바로 하나 더 쓸 수 있습니다. Esc 한 번이면 창이 닫히고, 한 번 더 누르면 고르기가 끝납니다.

윈도우 맥의 Option 은 Alt, ⌘ 는 Ctrl 입니다. 한글 입력 상태에서도 단축키가 그대로 됩니다.

5고치기 · 지우기

  • ↑ ↓ 로 메모를 고르면 그 장면으로 갑니다 → E 고치기 · C 완료 표시 · D 두 번 누르면 지우기.
  • 여러 개 지우기: 메모 왼쪽 작은 네모(또는 V)로 고르고 → «고른 것 지우기» (Shift+D).
  • 전체 지우기: Shift+X — 지금 영상의 메모 전부.
  • 지우기는 모두 3초 안에 두 번 눌러야 됩니다. 되돌릴 수 없습니다.
  • AI 가 고친 메모에는 초록색으로 ✓ 반영 · 무엇을 고쳤는지가 붙습니다(위 그림 맨 아래). 마음에 안 들면 «완료됨» 을 눌러 «다시 고쳐야 함» 으로 돌립니다.

6피드백 완료 → AI 에게

여러 영상을 다 보고 마지막에 한 번만 «✅ 피드백 완료» (Shift+Enter) 를 누르세요. 아직 안 넘긴 메모가 있는 영상이 전부 한꺼번에 넘어갑니다.

누르는 순간 요청 글이 복사됩니다. «영상 폴더마다 피드백 파일이 있으니 확인해서 반영해 달라» 는 글이라, 쓰는 AI 창 어디에나 붙여 넣으면(⌘+V · 윈도우 Ctrl+V) 됩니다. 클로드 코드를 쓰면 아래처럼 바로 넣을 수도 있습니다.

1⚡ 알아서 넘기기영상마다 그 폴더에서 열어 둔 클로드 코드 창으로. 없으면 그 폴더에서 새 창을 엽니다. 어디로 갈지 미리 보여 줍니다.
2🖥 한 창에 전체 넘기기열린 창 하나(또는 새 창)에 모든 영상을 한 번에.
3🎬 영상별로 고르기영상마다 받을 곳을 고릅니다. 하나 누르면 접혀서 고른 것만 남습니다.
4📋 복사만 하고 끝내기다른 AI 나 사람에게 직접 붙여 넣을 때.
안심 클로드 코드 창에는 «클로드 창끼리 말 넣는 길» 로만 넣습니다. 개인 작업 중인 일반 터미널에는 아무것도 치지 않습니다.
  • 클로드 코드를 안 쓰면: 4 복사만 → 쓰는 AI 에 붙여 넣기. 또는 창 아래 «새 창으로 켤 AI» 를 제미나이 CLI · 코덱스 · 직접 적기로 바꿉니다.
  • 넘긴 메모에는 «→ 넘김 · 어디로» 가 붙고, 다음에 누르면 새 메모만 넘어갑니다.
  • 받는 클로드 코드 창에 메시지를 받을지 묻는 창이 뜨면 수락을 누르세요.
  • 채팅만 되는 AI(웹 채팅 등)는 내 컴퓨터 폴더를 못 열어서 직접 고치지는 못하고 조언만 합니다.

7내보내기 — 사람 · 편집 프로그램에게

지금 보는 영상 하나를 넘길 때 씁니다. Shift+E 후 숫자.

  1. AI 에게 — 이 영상의 요청 글만 복사.
  2. 사람에게 — 장면 사진 · 시간 · 메모를 정리한 PDF 를 영상 옆에 저장합니다. 카톡 · 메일로 보내세요. (크롬이나 엣지가 있어야 합니다.)
  3. 편집 프로그램으로 — 메모가 타임라인 표시로 붙는 파일: 다빈치 리졸브 · 파이널 컷 프로 · 프리미어 프로. 캡컷은 표시를 불러오는 기능이 없어 시간표(.txt)를 줍니다.

8자주 묻는 것

메모는 어디에 저장되나요?
영상 바로 옆 «영상 이름.피드백.json» 파일입니다. 영상 이름을 바꾸면 메모 파일 이름도 같이 바꿔 주세요. 영상을 옮길 때도 같이 옮기면 메모가 따라갑니다.
영상이 안 나와요
크롬 · 엣지는 mp4(H.264 · HEVC) · mov 를 틉니다. ProRes 같은 편집용 형식은 안 나올 수 있습니다 — 맥은 사파리로 열어 보세요.
«페이지가 꺼졌습니다» 라고 나와요
30분 동안 안 써서 꺼진 것입니다. 시작 파일을 다시 두 번 클릭하세요.
새 판이 나오면?
새 압축 파일을 받아 풀어서 쓰면 됩니다. 메모는 영상 옆에 있어서 그대로 남습니다.
내 방식대로 바꾸고 싶어요
폴더 안 video_feedback.py 와 video_feedback.html 두 파일이 전부입니다. 쓰는 AI 에게 두 파일을 보여 주고 원하는 대로 고쳐 달라고 하세요.
«⧉ 따로 띄우기» 를 눌러도 창이 안 나와요
브라우저가 새 창을 막은 것입니다. 주소창 끝에 뜨는 «팝업 차단» 표시를 눌러 이 페이지는 «항상 허용» 으로 바꾼 뒤 다시 누르세요.
띄운 창이 자꾸 원래 모니터에 열려요
크롬 · 엣지는 허락이 있어야 다른 모니터 자리에 창을 엽니다. 띄운 창 위에 «🖥 다음에도 이 모니터에» 가 보이면 눌러서 허락해 주세요(한 번만). 그 단추가 없으면 창을 끌어 옮기면 됩니다.
인터넷에 올라가나요?
아니요. 페이지는 내 컴퓨터 안에서만 열리고(다른 컴퓨터에서는 못 엶), 영상과 메모는 내 폴더에만 있습니다.
